# Shashank Pabitwar — Portfolio

Simple, data-focused personal portfolio for Shashank Pabitwar. The page presents education first, then relevant experience, selected projects, and contact links.

## Live site

[shashankpabitwar123.github.io/Portfolio](https://shashankpabitwar123.github.io/Portfolio/)

## Main projects

- [PrepInterview AI](https://prepinterviewai.com/) and its [Tableau product analytics story](https://public.tableau.com/app/profile/shashank.pabitwar/viz/PrepInterview_AI_Product_Analytics_Aug_25_Revision/PrepInterviewAIScrollExperience)
- [PixelPlanes](https://pixelplanes.app/)
- CFPB Complaint Operations Analytics — Tableau, Snowflake, dbt, SQL, Python
- U.S. Airline Operations & Delay Analytics — Excel, Power Query, SQL, DuckDB, Python, statistics
- NYC Taxi January 2025 Analytics — Power BI, Power Query, DAX, star-schema modeling

## Site features

- Education → Relevant Experience → Projects content order
- One data analyst résumé throughout the site
- Responsive editorial layout with clear project links, metrics, and limitations
- Two separate, equal-size PrepInterview AI previews for the live product and Tableau analysis
- Accessible semantic HTML, keyboard focus states, reduced-motion support, and lazy-loaded project media
- SEO/Open Graph metadata, canonical URL, sitemap, and robots file
- Static HTML, CSS, and JavaScript hosted through GitHub Pages
